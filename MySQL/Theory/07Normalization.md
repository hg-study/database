### 키

> 키는 행을 구분하는 데 쓰는 열이다.

<br>

| **구분** | **후보키(Candidate Key)** | **기본키(Primary Key)** | **복합키(Composite Key)** |
| --- | --- | --- | --- |
| 정의 | 기본키가 될 수 있는 자격을 갖춘 모든 키 | 후보키 중 설계자가 대표로 선택한 하나 | 2개 이상의 열을 결합해 만든 키 |
| 개수 | 테이블에 여러 개 | 테이블당 1개 | 기본키나 후보키가 복합키일 수 있다 |
| 특징 | 유일성과 최소성을 만족 | 중복 불가, null 불가 | 한 열로 구분되지 않을 때 사용 |
| 비유 | 반장 후보들 | 당선된 반장 | 공동 반장 |

### 정규화

> 정규화는 데이터 중복과 이상 현상(삽입, 수정, 삭제 시 오류)을 줄이도록 테이블을 쪼개는 과정이다. 제1정규형부터 단계적으로 조건을 더한다.

<br>

| **단계** | **조건** |
| --- | --- |
| 1NF | 모든 값이 원자값. 한 셀에 한 값만 |
| 2NF | 1NF + 부분 함수 종속 제거. 기본키 일부에만 종속되는 열을 분리 |
| 3NF | 2NF + 이행 함수 종속 제거. A→B, B→C일 때 A→C 관계를 분리 |
| BCNF | 3NF + 모든 결정자가 후보키 |
| 4NF | BCNF + 다치 종속 제거. 서로 독립인 값들을 분리 |

---

### 제1정규형(1NF)

> 한 셀에는 하나의 값만 있어야 하며 반복 그룹은 허용되지 않는다.

<br>

**정규화 전** 홍길동의 전화번호가 한 셀에 2개라서 위반이다.

| **학생ID** | **이름** | **전화번호** |
| --- | --- | --- |
| 1001 | 홍길동 | 010-1234-5678, 010-2222-3333 |
| 1002 | 김영희 | 010-4444-5555 |

**정규화 후** 행을 나눠 한 셀에 하나씩 둔다.

| **학생ID** | **이름** | **전화번호** |
| --- | --- | --- |
| 1001 | 홍길동 | 010-1234-5678 |
| 1001 | 홍길동 | 010-2222-3333 |
| 1002 | 김영희 | 010-4444-5555 |

---

### 제2정규형(2NF)

> 1NF를 만족하면서 기본키(복합키)의 일부에만 종속되는 열(부분 함수 종속)을 제거한다. 기본키 전체에 종속되는 값끼리 모은다.

<br>

**정규화 전** 기본키는 (학생ID, 강좌이름)이다. 강의실은 강좌이름에만 결정되므로 부분 함수 종속이다.

| **학생ID(PK)** | **강좌이름(PK)** | **강의실** | **성적** |
| --- | --- | --- | --- |
| 1001 | 자료구조 | 공학관 120 | 3.8 |
| 1002 | 스포츠경영학 | 체육관103 | 4.0 |

**정규화 후** 강의실을 분리한다.

| **학생ID(PK)** | **강좌이름(PK)** | **성적** |
| --- | --- | --- |
| 1001 | 자료구조 | 3.8 |
| 1002 | 스포츠경영학 | 4.0 |

| **강좌이름(PK)** | **강의실** |
| --- | --- |
| 자료구조 | 공학관 120 |
| 스포츠경영학 | 체육관103 |

---

### 제3정규형(3NF)

> 2NF를 만족하면서 이행 함수 종속을 제거한다. 이행 함수 종속은 A→B, B→C일 때 A→C가 성립하는 상황이다.

<br>

**정규화 전** 학생ID, 강좌이름, 수강료에서 학생ID → 강좌이름 → 수강료로 이어진다. 학생이 강좌를 바꿔도 수강료를 따로 고치지 않으면 값이 어긋난다.

| **학생ID(PK)** | **강좌이름** | **수강료** |
| --- | --- | --- |
| 1001 | 자료구조 | 20000 |
| 1002 | 스포츠경영학 | 15000 |

**정규화 후**

| **학생ID(PK)** | **강좌이름** |
| --- | --- |
| 1001 | 자료구조 |
| 1002 | 스포츠경영학 |

| **강좌이름** | **수강료** |
| --- | --- |
| 자료구조 | 20000 |
| 스포츠경영학 | 15000 |

---

### BCNF

> 3NF를 만족해도 결정자가 후보키가 아닌 경우를 해결하는 강화된 3NF다.

<br>

**정규화 전** (강의실, 강의시간) → 담당교수이고, 담당교수 → 강의실이다. 담당교수는 결정자이지만 후보키가 아니다.

| **강의실(PK)** | **강의시간(PK)** | **담당교수** |
| --- | --- | --- |
| 101호 | 9시 | 김교수 |
| 101호 | 10시 | 김교수 |
| 102호 | 9시 | 이교수 |

**정규화 후**

| **강의실(PK)** | **강의시간(PK)** |
| --- | --- |
| 101호 | 9시 |
| 101호 | 10시 |
| 102호 | 9시 |

| **담당교수(PK)** | **강의실** |
| --- | --- |
| 김교수 | 101호 |
| 이교수 | 102호 |

### 제4정규형(4NF)

> BCNF를 만족하면서 다치 종속을 제거한다. 다치 종속은 기본키 A에 대해 서로 관계없는 값 B와 C가 함께 묶여 있는 형태로, 중복이 계속 늘어나므로 쪼갠다.

<br>

**정규화 전** 수강과목과 동아리는 서로 독립인데 한 표에 묶여 있어 조합마다 행이 늘어난다.

| **학생ID(PK)** | **수강과목** | **동아리** |
| --- | --- | --- |
| 1001 | 데이터베이스 | 연극동아리 |
| 1001 | 데이터베이스 | 사진동아리 |
| 1001 | 알고리즘 | 연극동아리 |
| 1001 | 알고리즘 | 사진동아리 |

**정규화 후**

| **학생ID** | **수강과목** |
| --- | --- |
| 1001 | 데이터베이스 |
| 1001 | 알고리즘 |

| **학생ID** | **동아리** |
| --- | --- |
| 1001 | 연극동아리 |
| 1001 | 사진동아리 |
